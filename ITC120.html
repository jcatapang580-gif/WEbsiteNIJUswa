ITC 120

ITC 120 is a course that focuses on programming concepts and application development. It introduces students to creating programs using languages such as VB.NET, while also covering fundamental topics like variables, data types, control structures, loops, functions, and basic debugging. The course helps students develop logical thinking and problem-solving skills by applying programming techniques to real-world scenarios, serving as a foundation for more advanced computing and software development courses.
